# Compliance FAQ

GDPR Requests

Customers may request:

- Data Export
- Data Correction
- Data Deletion

All GDPR requests must be processed within 30 days.

Compliance Requests

The following require escalation to Compliance:

- GDPR requests
- Privacy concerns
- Data deletion requests
- Regulatory audits

Security Incidents

Security breaches, ransomware incidents, unauthorized access,
and suspected data leaks must be escalated immediately.
